# 🎵 PULSE

PULSE is a fast-paced browser rhythm game where players hit notes in time with the music using the **D**, **F**, **J**, and **K** keys. Test your timing, build combos, and aim for a perfect score!

## 🎮 Features

- 🎹 4-key rhythm gameplay (D, F, J, K)
- 🎼 Procedurally generated note patterns
- 🎵 Built-in synthwave soundtrack using the Web Audio API
- ⭐ Real-time scoring and combo system
- 🎯 Accuracy tracking and performance ranking (S, A, B, C)
- ✨ Smooth animations and colorful neon-inspired UI
- 🌐 Runs entirely in the browser — no installation required

## 🚀 How to Play

1. Open `index.html` in your web browser.
2. Press **Space** or click **Start**.
3. Hit the notes as they reach the hit line:
   - **D**
   - **F**
   - **J**
   - **K**
4. Time your presses carefully:
   - 🟡 Perfect
   - 🔵 Good
   - 🟣 OK
   - ⚪ Miss

The game lasts **60 seconds**. Try to achieve the highest score and an **S Rank**!
